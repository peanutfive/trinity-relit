# 太平洋场景交付与地面校准（T25）

## 画面依据与范围

本批以现有 `pacific.js` 的七房连接为运行时合同，以本地原版核查给出的环境外观作画面依据。只新增2D资源和路网；原章的地图/时间/机关差异不在表现层补写，详见 `PACIFIC_SOURCE_AUDIT.md`。

- 台地是 Wabe 深渊中央石台，巨菌干上开白门；没有把它画成热带小岛。
- 脚手架是临时铁皮工业工棚，储罐、巨管、压缩机、细立柱与下行楼梯。底层是密管机房、墙装控制箱预留位、喇叭和滑门。
- 太平洋四面是狭小沙岸，中央为大片工棚，黎明金红天光、冷青海水。西海远处仅一棵棕榈的小岛，未用丛林度假海岛替代。
- 四侧出入工棚和当前 `mesa` 的别名出口仍属于已有改编模型，不把这批画面视为原版拓扑已修正。

所有场景逻辑坐标为480×288，图片按5:3单幅缩放。人物仍用完整6×3足底及0.25路线采样；海水、峭壁、机具、菌干与大岩堆不走。相同目的地的别名只显示一个门口。上下层、白门和厂棚门需按F，不靠贴边自动传送。

## 校准中发现并纠正的问题

1. 第一版北滩厂棚占去整个右路；几何放行会使人走过屋顶或墙体。已用内置 image_gen 定点改图，下移并缩小厂棚，保留完整东西沙带，再按最终PNG重描地面。未用扩大可走区蒙混。
2. 第一版南滩左右边缘植物和岩石挤入道路。已定点清出砂地，保持厂棚/门/坡坐标不变；最终西东口实际落在净沙地上。
3. 西滩大岩堆阻断直线东南行程。地面明确绕其右侧海岸，不把路线画成穿石。测试路线应走300,182→385,191→440,215→466,250附近，再向南到出口。
4. 台地默认出生点曾距离白门传感圈清除阈值差0.24像素。默认站位右移至255,143，七房来源退离检查按原标准通过；没有降低判定标准。
5. 台地巨菌追加实际轮廓前景遮挡，人物走到其背面时不会盖在伞盖之上。

## 生成与复核记录

七份 `art-prompts/pacific-*-v1.md` 保存实际完整提示词、每幅最终原始文件路径和引用图。使用内置 image_gen，每个场景独立请求；北/南两幅另各有一次定点编辑。项目交付PNG是选定生成文件的原样副本，生成器原文件保留，没有额外压缩或程序重画。
