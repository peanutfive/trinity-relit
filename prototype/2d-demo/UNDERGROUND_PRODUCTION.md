# 墓穴连接区与地下章制作记录

2026-10-29，T21。延续双版本2D开发授权，沿既有章节制作，不修改文字版入口、共用引擎、解析器、物品或章节规则。新增八个场景：Wabe从14/30推进到19/30，日本2房保留，地下3房接通；当前共35个视觉场景。原版忠实性与2D表现分别验收。

## 可玩路线与操作

坑缘NW进入断崖，沿右侧窄路到小屋，经小屋南门、墓地、古墓、露天纳骨堂，按日晷Pluto符号进入地下。没有传送选章或额外捷径。断崖SW和小屋E仍是未制作边界；墓地入口与古墓深门须F确认。IN/OUT别名共用实际口，不生成重复门。

小屋中央铁锅有蒸汽、实体基座及前后遮挡；地图和鸟笼按画面轮廓观察，肥皂泡独立绘制并可取。古墓门洞与小孔分开命中，拿着原章钥匙时可以试用；当前原章并不把通行绑在开锁flag上，表现层没有擅加门槛。纳骨堂采用露天骨骸洼地，巨菌门沿用已有同画风独立素材，显隐随真实符号变化。

地下第一室可观察裂缝与落石；裂缝禁行，左右隧道沿同一石地贯通。中室的对讲机和末室的灯笼只在原状态确实位于本房时出现。F先观察，再拿取；背包选择灯笼后按F点亮，携灯时在手边绘制且照明随状态改变。在背包中可放下手中物品，不增加常驻按钮。中室灯笼与木片分开放在固定的安全位置，避免彼此覆盖或拿走一个后另一个跳位；通用掉落物的完整空间持久化仍为后续工作。

原章光源条件保持：携带发光木片，或携带点亮的灯笼，或中室留有点亮的灯笼，才能安全进入中室。无光致命反馈仍由原章触发；没有因2D环境可见就跳过死亡。灯笼留置、取回和白门返程均使用合法命令。门口短步行导演复用实际地面，不再提交命令；暂停、跳过、M及存读档不重复入场或物品生成。

地下M地图为独立岩洞轮廓，三房分别标为裂隙、电缆通道和圆筒室，按探索揭示名称；这些是中文界面辨识标签，未改原房间名或英文。Wabe小屋移至断崖附近，墓穴在图中单列示意连接；地图不改变出口或回合。
