# 2D 自动物品提醒审查（2026-10-24）

范围：当前已绘制的19个场景；不是对尚未制作的130个运行时房间的全面删改。

原则：进入房间/环顾时，已经由画面明确呈现的可交互物件不再自动点名或报位置。原版英文与中文源文件完整保留，仅在2D显示适配中按准确句子、当前可见对象和输出来源筛除。玩家主动查看、剧情演出、声音/对话、无法从素材读出的铭文和状态变化保留。不按关键词全局删文。

## 已审查但不机械删除

- 宫殿门：天气、氛围、可见路线。没有独立物件指路句需要本轮移除。
- 圆池塘：普通水禽和船队为环境叙事；小纸船/折纸鸟的认知转变由既有探索机制控制，揭示与纸上文字保留。
- 兰开斯特门：费力撑伞、强风、伤疤、失落、擦泪等为事件内容；树上的足球若没有独立可见素材，不抹掉其仅有的文字状态证据。
- 长水湖、涉水：导弹的缓慢坠落、白门出现及通行条件属于剧情/异常现象，不作为普通拾取物提醒删除。
- 日晷草地：指针已经缺失的状态未在所有素材条件下明确可读，保留缺失状态文字。
- 山顶、北沼泽、楼梯底部、林中空地、棚架：主要为环境和道路，没有需移除的独立拾取物自动点名。
- 日晷顶点：符号、铭文、当前环位与影子的精确信息无法从缩小素材可靠读取，保留；主动查看始终保留。
- 主动尝试被阻挡出口时的原版原因反馈保留；这是操作结果，不是进场自动报物品。后续可按原版规则专项另行设计反馈层，不静默隐藏失败。

## 素材语义修正

花径底部的旧平面牌子实际上绑定“阿尔伯特纪念碑”事件，和远处建筑不一致。本轮删除该占位牌，查看热点迁至画面远处的纪念碑。真正的草坪告示牌改用同画风木框/金属立柱透明素材。
