# 牧场石墙外围 · 步行灰盒

T32 的五幅图供场景美术定构图、关卡验路。玩家沿同一堵低石墙绕过破败的牧场屋，经过东侧的前院时能看到混凝土水库。图中北方朝上，坐标以 480 × 288 的角色脚底平面为准。地点之间的相对方位来自章节，曲线、路宽、建筑取景和落点是本次构图设计。

## 美术接手与验收

- 浅沙色实线区域是本批核验的足底通行面。灰黄色虚线标志后续要制作的支路，房屋、墙头和水库的轮廓用来给玩家辨向。生成正式背景时保留各路口在边缘的次序，让路色和车辙随道路连续转弯。
- 牧场西北、西南的默认描述显示院门闭合，现行文字出口可以直达内院，项目文档列有铁门状态缺口。草图保留闭合门扇和门前接近空间。牧场东南保留敞开的门扇。制作门前动线时以同一门的实际脚点处理方向别名。[门与跨章差异](../RANCH_REWRITE_GAPS.md)
- 原版浅坑东南与牧场西北的铺装路可互返，文字版已有牧场西北向西北返回浅坑的出口；浅坑当前只有向西和向东的出口。牧场西北另有一条通往棚屋后的现行北向返程桥，原版此方向的山麓尚未映射。西北图只描资料明确的西北铺装路，北向桥保留为无图形的制作备注。[沙漠章节](../js/data/desert.js) · [牧场边界记录](../RANCH_REWRITE_GAPS.md)
- 独立灰盒只读取每幅 SVG 的 `ring-ground` 多边形。按主环十个方向检查双脚空间、转弯连续性、回程落点、沿墙走时是否会被支路误触。正式背景到位后逐图重描路肩、石墙底座、门柱与遮挡，并在正常游戏流程补验跨章、地图揭示和刷新续玩。

本次用现有足底碰撞和寻路分别检查了五个起点、十个路口和十个返程落点。角色从各图起点均能走到本图两个路口及两个返程落点。十个落点均在相应出口的触发半径外。该检查在独立灰盒上运行。
