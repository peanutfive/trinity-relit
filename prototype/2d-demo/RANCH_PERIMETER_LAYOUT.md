# 牧场石墙外围 · 构图与实景步行

T32 已有五幅原创背景和独立的实景布局。沿石墙一圈可以看见同一幢破败的牧场屋，在东侧前院还能看见水库和上平台的木坡道。图中北方朝上，坐标以 480 × 288 的角色脚底平面为准。方位来自章节，路肩、门槛和弯道按实际交付画面取样。[实景布局](ranch-perimeter-layout.js)

## 实景与灰盒的差别

- 灰盒中的浅沙色实线是外围主路，虚线是后续支路。正式背景把西北角的东侧路口从草图 y=113 提到 y=88，东南角的西侧路口从 y=180 提到 y=163，五景的通行面与返程点均重新取样。
- 实景布局的 `exitAnchors` 只有主环每景两口。角落处接近门的短径和水库两侧的支路可以步行，`reservedFeatures` 单独记录后续区域名称、方位别名和所在位置。西北、西南两扇闭门的门前位置可达，脚底碰到门槛即止。东南门扇向院内折回，角色能踏进可见的门洞。
- 牧场西北、西南的默认描述显示院门闭合，现行文字出口可以直达内院，项目文档列有铁门状态缺口。草图保留闭合门扇和门前接近空间。牧场东南保留敞开的门扇。制作门前动线时以同一门的实际脚点处理方向别名。[门与跨章差异](../RANCH_REWRITE_GAPS.md)
- 原版浅坑东南与牧场西北的铺装路可互返，文字版已有牧场西北向西北返回浅坑的出口；浅坑当前只有向西和向东的出口。牧场西北另有一条通往棚屋后的现行北向返程桥，原版此方向的山麓尚未映射。西北图只描资料明确的西北铺装路，北向桥保留为无图形的制作备注。[沙漠章节](../js/data/desert.js) · [牧场边界记录](../RANCH_REWRITE_GAPS.md)

## 验收范围

独立灰盒通过五图十向复核。实景布局使用游戏现有足底碰撞、连续步行、寻路和来源落点逻辑，覆盖十条去返方向、41 段沿路取样、15 处墙池或院内阻挡，以及各图八个地面物品落点。十个来向落点均在返回路口的感应半径外。[灰盒复核工具](tools/review-ranch-perimeter.mjs) · [实景回归](checks/ranch-perimeter.test.mjs)

本批在独立牧场场景集上验收。正式接入仍需打通浅坑前往牧场的东南出口，并从正常游戏进度验证进出章节、地图揭示和刷新续玩。
