# T22 藤架翻转区与地球轨道制作记录

2026-10-29启动，2026-10-30验收。沿人类持续授权完成2D表现，范围仅为本目录及TASKS/SHIP_PLAN；原引擎、解析器、物品、章节和出口真值只读。开发分支 `codex/2d-garden-demo`，不合并或部署main。

## 交付范围

新增植物园、藤架顶部、北侧藤架、南侧藤架、北/南崖柏通道、瀑布七个Wabe房间；跨蘑菇门进入轨道近景/远空两房，并可返回。当前44个场景：序章11、Wabe26/30、日本2、地下3、轨道2。默认状态67个热点、152条已绘制出口，144条来源落点按真实返回口匹配。数字只代表当前适配结构，不能证明原版忠实性。

棚架、南沼泽、北沼泽和林中空地四个已有场景同时重制。新区域接入前，未制作目标被场景目录过滤，旧审计因而漏掉通向它们的道路错误：棚架缺SE/SW/U、N与NW共路；南沼泽W落在灌木；北沼泽SW落在水里；林中空地NW落在实心树林，南侧却有无规则道路。只给新房间画图会把这些问题重新暴露给玩家。

本批按全部实际方向先做灰盒、再生成独立画稿、最后按交付图校准地面和接点。棚架保留七条地面路与独立上行根阶，未制作的河流等道路有制作边界；侧藤架按当前规则只画一个可返回入口，不画第二条假通路。瀑布不画当前规则不存在的冰洞或墓地楼梯。

## 交互和演出

- 斧头为独立透明素材，嵌在可接近的右侧树根上；第一次F观察，第二次F拿取，物品从场景消失。绘制点与脚底接近点分开，斧头不放在人物够不到的高树干。
- 棚架上行和顶部下行阶梯用F确认，地面道路用WASD/方向键。入场依来源匹配返回入口，保持传感区内侧安全距离。
- 翻转只读取真实 `state.flipped`。顶部N/S出口的当前规则提交一次翻转，导演只回放沿地面前行再淡出；暂停、跳过、地图、读档不重复命令。植物园背景水平翻转，东西出口、地图和返程口随当前真实状态更新。
- 瀑布蘑菇门沿用日晷Mercury符号和肥皂泡前置。错误符号、缺泡膜与成功进入分别由原章裁决，表现层不放行。
- 轨道沿用当前章的方向浮行规则。主角使用同一角色图集的空中姿态与透明泡膜，无脚底影、无路程步态、无地面尘叶；近景/远景为同一罐形卫星。外壳有独立占位和前后遮挡。
- 泡膜边缘可点击观察，但不抢走F对其他附近目标的选择。背包选斧头后，在卫星近景按F尝试破泡，沿当前命令返回瀑布；泡被销毁，斧头保留。泡膜不提供“放到真空地面”的按钮。
- 返程薄膜扩开、碎光、人物向白门移动和淡出为只读短演出，不增加原版没有的倒计时、磁吸进展或死亡。远空无法直接破泡返程，仍须依当前章回到卫星视点。
- M新增独立轨道星图、地球弧面与漂行关系线，不伪装成地面路网。模型保留全部22个方向关系，界面按相同目的地合并展示；名称只随访问揭示，手机自动定位放大，保留全图总览。
- 隐藏轨道进场中直接提醒喜鹊解谜线索的现有句子，保留主动查看和事件反馈。没有增加英文剧情或实时翻译。

## 实际行走发现的修复与后续规范

1. 南侧藤架在 `(264,113.2)` 处，0.5像素路径采样跳过了足底接触，路径合法判断与实际逐帧行走不一致。现在新区域用0.25像素检查，该窄弯用0.1；保留真实卡点路径的密采样回归。
2. 北崖柏弯角的带状多边形末端没有覆盖画面上完整的宽转角；独立看图取样发现 `(267,184)` 不可落脚，已补实际可见转角地面，不缩人物足底。
3. 顶部下行阶梯必须同时拥有F热点，不能只把出口设成“仅互动”而没有操作入口。
4. 南沼泽NE虽接未制作的裂隙边缘，画面已绘制道路，必须登记制作边界，不能因目标尚无场景而静默漏掉。
5. 蘑菇门使用完整32×10脚底实体；三条岸路必须能绕行。点击可见门冠是互动，实走验收须选可见地面，不能通过扩大/挪开点击形状假装道路已通。
6. 新房间接入要重新查所有相邻旧房间、两种翻转状态、全部方向别名与来源落点；只查默认状态或只点文字箭头不够。

## 图像来源与保留

全部新位图由内置 `image_gen` 制作或编辑，未调用外部付费脚本。原始PNG不重绘、不切图覆盖；Canvas直接取样。每幅完整实际提示词与灰盒SVG均保留在 `assets/`。灰盒记录设计意图，运行地形以交付PNG复核结果为准。

|---|---|
| 棚架、南/北沼泽、林间空地 | `trellises-v2`、`south-bog-v2`、`north-bog-v2`、`forest-clearing-v2` |
| 植物园、顶部、南/北侧藤架 | `arboretum-v1`、`arbor-top-v1`、`arbor-north-v1`、`arbor-south-v1` |
| 南/北崖柏通道、瀑布 | `arborvitaes-s-v1`、`arborvitaes-n-v1`、`waterfall-v1` |
| 轨道近景、远景 | `orbit-satellite-v1`、`orbit-space-v2` |
| 斧头 | `arbor-axe-v1.png`，1254×1254 RGBA，取样框 `[51,71,1175,1143]` |

森林/轨道背景约1620×972、5:3，按各自原始尺寸保留。`orbit-space-v1` 的卫星意外带有太阳能板，未接运行时；v2以近景为参考统一罐形和天线。废稿原图与提示保留便于追溯，不将其算作另一场景。泡膜复用T21 `ug-props-v1` 的同一透明取样。

背景改为按实际进入的房间加载，同一图集只请求一次并保留缓存；等待目标画面时保留来源快照，防止裸露占位路面或下一房人物先出现。标题冷启动只请求序章首图，不预先下载所有章节。角色与道具图集目前仍是共用加载，尚未声称已完成全部资源流式管理。

## 原版与现有适配的差异

本批在本地原始程序只读审查及现有引擎合法命令上核对，不宣称完成轨道原机全流程复现。以下属于原规则债务，继续遵循人类“先完成2D表现，暂缓原规则修正”的决定：

| 位置 | 原版证据与当前适配的分歧 | 本批处理 |
|---|---|---|
| 藤架连接/翻转 | 原版植物园通过南北侧与顶部相接，并在从另一侧下去时翻转；现有从棚架U入顶部，顶部N/S立即翻转，两侧只是返回顶部的死端 | 原方向与状态裁决不改，明确只画当前可走路线 |
| 黑暗与Klein结构 | 原版顶部照明条件、约八英尺的Klein晶体结构及物品传输/反转尚未被当前章完整表达 | 不伪造可用机关或用画面宣称谜题完成；未把当前两态连线等同原版机制 |
| 瀑布连接 | 原版西向瀑布/观察后的冰洞及通往墓地的阶梯，与当前北侧水幕和三条林路适配不同 | 不在画里偷偷添加无规则出口，留待原规则专项 |
| 泡膜来源 | 原版由巨型男孩吹泡送行；当前在小屋拾取肥皂泡 | 使用当前真实前置，不生成两套泡或伪造男孩剧情 |
| 轨道推进/磁铁 | 原版无推进移动、磁铁附着与阶段进展决定事件；当前为两房自由方向浮行，金属在陨石坑固定且无法合法携带，通常不能触发卫星磁铁事件 | 不赠送磁铁，不补自动吸附、倒计时或爆炸 |
| 破泡时机与工具 | 原版泡膜破裂时机与锋利工具条件更完整；当前卫星视点持斧即可破泡或OUT | 只实现现有命令的可见动作，不能把这段称作完整原版轨道解谜 |
| 场景原文 | 当前顶部、侧藤架等仍有既有TODO/文本归属与来源待核 | 沿用同一静态中英文本，不自创新英文；保留文本审查债务 |
