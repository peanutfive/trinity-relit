# 浅坑、牧场与水库

浅坑的东南公路通往牧场西北角。从牧场沿同一条铺装路返回，会站在浅坑的东南路肩。两个方向都使用共用章节的出口，章节切换保留随身物品和探索记录。

## 绕水库走一圈

| 来路 | 去程 | 回程 |
| --- | --- | --- |
| 牧场东北 → 水库北 | 东 | 西 |
| 牧场东南 → 水库南 | 东 | 西 |
| 前院 → 水库北 | 东北 | 西南 |
| 前院 → 水库南 | 东南 | 西北 |
| 水库北 → 风车下 | 东南 | 西北 |
| 水库南 → 风车下 | 东北 | 西南 |
| 水库南 → 水库边缘 | 沿短阶上行 | 从同一段台阶下行 |

可以从前院绕水库一圈回到原地。地图上的两条岸路绕开水面，新地名在第一次走到时出现。上下台阶需要靠近按 F 或点选台阶，原版的「北／上」与「南／下」各对应一个实际入口。

## 验收依据

- 在原版解释器中从开局重走到浅坑，向东南到达牧场，向西北返回。在正常取得的原版南岸存档上逐组核对了表中各路及台阶的两组方向别名。
- 网页实走从标题的「开始」进入，经序章、异境、渡船、小岛白门抵达浅坑。中途只使用游戏提供的导出及导入功能接续。进出牧场时核对脚下位置、朝向、回合、物品和存档。[浏览器走图工具](tools/browser-ranch-journey.mjs)
- 对照现行章节逐条检查脚下通行面与库壁。南岸短阶通往干燥的水库边缘。水中游动及风车平台有各自的原版动作和物品状态，分开制作。[通行回归](checks/ranch-reservoir.test.mjs) · [原版条件差异](../RANCH_REWRITE_GAPS.md)

## 风车与水下

风车下的梯子和上层梯口各有一个 F 热区。上层只容许在腐朽的方木台上行走。登梯、停留和再次登梯会继续消耗木台的承重余量，短暂离开会保留已经出现的裂损。伸手拿边缘的望远镜时，木台沿轴翻折，玩家落水。望远镜、手上拿的东西和台上的散物一起沉底，放在口袋或穿在身上的物品留在原处。

在水面游到开阔处，按 F 或点人物可以下潜；潜水时自动屏息。在原版中，木片握在手中或沉在水底都能照明。正常发光的防水灯也能照亮水底。该条件按原版照明例程核对，带电亮灯已做游戏状态回归。没有光时，水底的散物无法辨认或拾取。触屏在全黑时会显示「浮上水面」。屏息靠原版动作推进，游动、看地图、关闭对白或读档都不会消耗一次呼吸。亮处靠近望远镜按 F 可以拾取，首次找回加一分。

水下游到空处再按 F 即可上浮。靠近画面南边的混凝土平台按 F 上岸，从同一段台阶回南岸。望远镜可以挂在脖子上，也可以在南岸朝风车举镜。上岸后回到梯脚，可见木台已经翻折。

从正常开局进入异境，在南沼泽拾取发光木片，经原有路线进入牧场。在正式网页走完登梯、伸手、潜水、拾镜、上浮、返岸、远望，并在木台、水面、水底和返岸后刷新续玩。暗处的拾取失败、自动上浮、旧存档兼容和再次拾镜的分数均另有回归。[正常浏览器路线](tools/browser-windmill.mjs) · [章节规则回归](checks/ranch-windmill-story.test.mjs) · [水面与演出回归](checks/ranch-water-presentation.test.mjs)

## 前院到前廊

前院的缓坡穿过石墙缺口。按 F 沿坡到达牧场屋东侧的高木廊，返程沿同一条坡下去，落在朝向前院的坡脚。原版前院的西、上、入都走这条坡，前廊的东、下都回前院。廊上两扇门和南北尽头各在原版对应位置，南北分别通东北院与东南院。[前廊往返回归](checks/ranch-front-deck.test.mjs)

## 东墙内外

从木廊向北可到东北院，院内西侧的外门默认关闭。靠近门扇按 F 可以开、关门；石墙围住庭院的另外两侧。卧室内部留待后续制作。从前廊向南到东南院，东南角敞着的铁门可通石墙外的牧场东南。出门回身能从同一个门洞进院，沿屋侧向西则到当前场景边界。[两院通行回归](checks/ranch-east-yards.test.mjs)
