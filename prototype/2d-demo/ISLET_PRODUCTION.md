# 雾中小岛与沙漠抵达区

2026-11-23 · T27 · 2D 开发分支

## 可玩范围

当 Wabe 的日晷对准 α 时，渡船出现在河岸。玩家走到岸边可以按 F 观察，再按 F 登船。点按船身也可完成这两次交互。角色登岛时站在靠船的一侧。小岛北面的沙颈连通沙洲，两处菌门均可抵达浅坑。浅坑东西两侧各有一片可探索的沙地，继续向外会看到制作边界。

五个场景分别使用原创背景。碰撞和角色落点按最终画面的岸线、开口、浅坑鞍部描绘。渡船与船夫共用四姿态透明画，船底沿水线轻微起伏。沙洲与小岛的菌盖按角色前后关系遮挡。雾岛和沙漠各有一张章节地图，按 M 查看已探索地点。

## 规则与原版对照

| 项目 | 仓库现行文字规则与本次 2D 行为 | 原版正常游玩记录 |
| --- | --- | --- |
| 登船与船资 | α 开放后可直接登船。没有返航条件时，第二次 F 显示单程提示。 | 玩家在墓穴取得裹尸布与银币，穿裹尸布上船，在船上付款。 |
| 登岸 | 从河岸直接抵达小岛，向北可到沙洲。 | 先抵达沙洲，再向南到小岛。 |
| 白门 | 小岛与沙洲的白门均通往浅坑。 | 实测小岛白门抵达木屋。沙洲白门的目的地待核验。 |
| 返航 | 游戏接受银币后可从沙洲返河岸。当前适配尚无正常取得银币的途径。 | 本次所据原版记录未覆盖返航条件。 |

原版对照依据为本机 Release 12（860926）从正常开局取得的试玩记录，参考步骤 87–92 与 104–113。本批使用既有文字规则驱动 2D，未把原版转录或派生数据纳入提交。

## 验收

- 浏览器先用正常游戏指令取得渡口关闭和开启的河岸存档，再通过游戏的导入界面开始实走。检查了关闭时渡船隐藏、岸上点击与步行、F 登船、未付费返航的反馈、两处白门的来向落点和沙地两端的边界。
- 独立付款用例向正常河岸存档加入一枚银币，检查交付一次、返河落点和触屏再次登船。此用例只验证持币后的行为。
- 以实际输入完成九次道路切换和五次 F 通行。桌面与手机地图、刷新恢复、首次登岛描述去重和原序章流程通过。可重复运行 [渡口浏览器验收](tools/browser-islet.mjs) 和 [场景检查](tools/audit-scenes.mjs)。
- 整个 2D 版现有 71 个场景、106 个默认热点与 249 条默认出口。265 项 2D 检查、95 项项目测试及章节规范通过。出口真值比对的 43 项既有偏差与前一版一致。
