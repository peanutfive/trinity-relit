# Wabe四处探索区域制作记录

2026-11-02，T24。按人类持续的2D开发要求，补齐深渊边缘、岬角、药草园和河流。当前48视觉场景，包含Wabe全部30房；这是画面与当前适配规则的覆盖，不代表原版机制或全部道路美术已验真。原引擎、解析器、物品、章节和真值均未改。

## 画面与实际通行

- 深渊边缘：六条分开的岸路，北侧裂隙不可跨越，对岸为平顶岩台及台上毒菌。没有用桥、倒树或跳跃动画伪造尚不存在的规则。
- 岬角：南/东南两路与山崖分明。男孩原文约四十英尺高，因此坐姿约130逻辑像素，对照35像素高主角是有意的剧情尺寸；肥皂水碟约47像素宽。坐姿身体、右鞋和巨碟分别占位，不把整张人物透明边框当墙。
- 药草园：只开放西侧院门，七片药床不可踩入；菌干有实体占位，观察站点在前方土路。近侧木栅和两片门叶分别做前景遮挡。蒜瓣依现有物品位置出现，先观察再拿取；百里香不可拿。
- 河流：三条N/W/NW岸路，暗绿静水、倒影和薄雾，水面及石岸不能踩入。没有画当前无法操作的渡夫、渡船或蘑菇门。

先做路网灰盒，再按交付PNG校准。药草园西门实际在y160，河流北口x273、西口y146，与初稿不同；碰撞、出口、来源入场、点击和验收路点都跟交付画调整。保持6×3足底和0.25像素连续采样。

十二条新房普通出口及旧邻接共十一组、二十二个方向均保留原章目标。进入时站在对应的返回路口内侧，不回默认起点；三个未制作的跨章IN只显示制作边界，闭门时也不会产生“进入本房”的假自出口。M地图只揭示已走地点，无传送或额外回合；四房存读档不重演进入事件。

## 演员与交互

巨型男孩依游戏时钟循环休息、浸棒、举到嘴边、吹泡和泡漂散。四帧使用各自实测脚锚；动作与泡的计算共用只读采样函数，暂停冻结，关闭动效静止。没有自动赠送道具或提交原版回合。

过渡帧先在复用的透明离屏画布线性混合，再一次绘入世界，避免两次普通透明叠加使整个人物半透明。浏览器在多处过渡中段检查实像素身体alpha，兼看正常帧率、首中尾和主角在鞋前停住的截图。精灵的真实脚点用于排序，与观察站点分开。

点击轮廓按实图校准：远处小毒菌不以大块岩台代替；耳机优先于巨大身体；七片药草用同一稳定对象ID的多多边形并集，土路空隙不触发药草，百里香细部优先。无效或非有限命中距离被拒绝。F仍使用同一近处/朝向裁定，观察原文与物品所有权交原引擎。

观察站点、实体足底和绘制排序是三个不同坐标。菌干前的观察点不能拿来排序，否则站在菌干前的主角会被菌干错误盖住。所有有绘图偏移的实体均须按真实脚点声明深度。场景校验工具的旧6像素网格漏过药床窄道，现按控制器4像素密度检测并复用单房结果；没有扩大地面、缩小足底或降低路段精度。

进场只隐藏已被画面明确呈现的重复对象介绍：深渊旧几何段落、巨人坐姿/吹泡/碟和药草园毒菌。主动查看、声音、四十英尺的原文尺寸、百里香文字和河流气氛保留，标记见`visual-text-policy.js`。不实时生成或重译剧情。

## 原版差异与范围边界

只读核对了本地DAT对象306/370/417/565及原始程序对应地点、人物和事件定义；普通道路与当前章一致。以下机制属于既有原规则债务，继续遵循人类暂缓决定：

| 部分 | 原版与当前适配的差异 | 本批处理 |
|---|---|---|
| 深渊与台地 | 原版北侧为隔三十英尺的岩台，需要橡树桥；毒菌位于台顶。现章把台地/毒菌描述和跨章IN简化合并 | 画正确的分离岩台，不增加可走桥；主动查看中的旧错文保留待原章专项 |
| 巨人肥皂泡 | 原版有进入巨碟后包膜与巨人吹送；当前章只有三种观察，泡仍在小屋拾取 | 常驻吹泡只读，不赠泡、不伪造巨碟进入操作 |
| 蒜瓣和园门 | 原版蒜藏在废料堆中且已腐烂，园门受小屋后门状态控制；当前鲜蒜直接可取、西门恒通 | 依当前真实物品和通行状态呈现，不在表现层新增搜寻或锁门条件 |
| 河流 | 原版为渡船、渡夫与多阶段渡河；当前Alpha条件直接切到Islet | 不画可玩假船/门，保持未制作章节边界，后续按专项核实机制 |

Pacific、Tundra、Islet仍未2D制作。下一批按章节顺序先接太平洋分支；旧道路美术、更多前景、环境声、Phaser迁移和其它原规则差异继续分别跟踪。
