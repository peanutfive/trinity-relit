# Trinity · HD-2D 探索版

开发依据：[2D开发计划](DEVELOPMENT_PLAN.md)。当前可游玩肯辛顿花园序章全部11房，并接续Wabe首批8/30房；这是沿现有规则的表现版，原版规则差异按人类决定暂缓修正。制作与证据边界见[序章制作表](PROLOGUE_PRODUCTION.md)及[Wabe制作记录](WABE_PRODUCTION.md)。

启动仓库开发服务器，打开 `/2d-demo/`。

- 方向键 / WASD行走，Z / 回车与附近对象互动；动作菜单执行查看、拾取、购买、交付、推动等操作。
- I打开背包，再选择物品与操作；L环顾、H提示、F全屏。
- Esc打开暂停与设置，内含改键、画面和音量；探索时不显示常驻键位栏。手机提供方向与互动按钮。
- 中文、英文和双语使用同一份既有章节文本，不实时翻译。
- 白门后可探索草地、山顶、南北沼泽、楼梯、日晷顶点、林中空地和棚架；转动符号环，拾取或放下发光木片。
- 操作后自动保存，标题可续玩；Esc的“探索进度”可手动保存、读取及导入导出。

全序章背景、老妇人、鸽群、走鹃、红宝石、婴儿车、雨伞、纸鸟、日晷和白门采用统一原创素材。两位老妇各有独立肖像。事件导演根据引擎执行前后的状态播放短动画，可跳过，暂停时冻结；不修改flags、物品或分数。

角色为原创四方向像素动画，脚步按实际位移驱动，具备呼吸、查看、拾取与推车等表现。背景仍采用概念图集，完整前景分层遮挡和精细地形碰撞待制作。实际图像提示词保存在assets目录，未使用参考游戏的商业资产。

2D入口独立导入现有GameEngine、Parser、章节和物品，不修改这些模块、不加载语义模型。2D进度和设置分别保存，与文字版存档隔离。恢复不重放进入事件，死亡不覆盖活档，坏导入保留已有进度。

验证方式：

```sh
npm run verify
npm test
node --test prototype/2d-demo/checks/*.test.mjs
node prototype/2d-demo/tools/audit-scenes.mjs
```
