# Trinity · HD-2D 探索版

开发依据：[2D开发计划](DEVELOPMENT_PLAN.md)及[人物空间与探索修订](EXPLORATION_PLAN.md)。当前可游玩肯辛顿花园11房、Wabe 26/30房、日本游乐场/避难所2房、地下3房和地球轨道2房，共44场景；这是基于共用规则的表现版，T19已按原版实测修正序章时钟与长水湖，其余规则差异仍按人类决定暂缓。制作与证据边界见[序章制作表](PROLOGUE_PRODUCTION.md)、[Wabe制作记录](WABE_PRODUCTION.md)、[日本章节记录](JAPAN_PRODUCTION.md)、[崖壁区域记录](CLIFF_PRODUCTION.md)、[地下章节记录](UNDERGROUND_PRODUCTION.md)及[藤架与轨道记录](ARBOR_ORBIT_PRODUCTION.md)。文字版仍由仓库原入口单独提供。

启动仓库开发服务器，打开 `/2d-demo/`。

- 方向键 / WASD行走，F优先与面朝的附近对象互动或继续对话；默认回车和Z不执行游戏互动。空处按F不自动环顾，L用于环顾并结算一个原版动作周期。T看表，R等待；序章T不推进时间，R通常经过60秒，显著事件可打断。
- 直接点击物体的可见形状，主角会沿地面接近；手动移动或新的点击会取消上一次自动走近请求。第一次触碰先观察，之后按对象状态拾取或操作；未观察的对象只提示“观察”，不提前显示名字或解谜动作列表。
- I打开背包，选择物品拿在手中，再对目标使用；×收起手中物品。点击手中纸鸟可近看；直接点击纸张展开、阅读。H提示，F11全屏。
- M打开章节探索地图，可拖动、缩放和定位；地形轮廓始终可辨，地名随探索揭示。地图不传送、不推进回合，M或Esc关闭。
- Esc打开暂停与设置，内含改键、画面和音量；探索时不显示常驻方向、互动或Esc按钮。手机点地行走、点对象互动；右键或双指轻触可打开菜单。
- 中文、英文和双语使用同一份既有章节文本，不实时翻译。
- 白门后可探索草地、山顶、南北沼泽、楼梯、日晷顶点、林中空地和棚架；转动符号环，拾取发光木片。背包选择物品后，可再次打开背包放下手中物品。
- 楼梯东北支路、弯道北路及荒野西北路接入崖壁区；F观察蜂巢/冰锥/坑沿/金属，并确认进出岩洞或沿缓坡上下坑底。M只标记已走过的地点，返回从对应入口内侧站定。
- 棚架F登藤架，探索植物园与南北崖柏通道；瀑布门按当前符号/肥皂泡条件通往轨道，背包手持斧头可尝试返程。轨道M是独立星图，人物在泡膜内浮行。原版与当前规则差异见制作记录。
- 操作后自动保存，标题可续玩；Esc的“探索进度”可手动保存、读取及导入导出。

普通换房从来源对应的入口内侧出现、朝向场景内部；向房内走不会误触返程出口。门柱只按基座碰撞，圆池塘可沿素材左岸和北岸走到右上东北小径。

全序章背景、老妇人、鸽群、走鹃、红宝石、婴儿车、雨伞、纸鸟、日晷和白门采用统一原创素材。两位老妇各有独立肖像。事件导演根据引擎执行前后的状态播放短动画，暂停时冻结；F或点击对话框只翻页，跳过演出需单独点击明确按钮。演出不修改flags、物品或分数。

角色采用与NPC相配的原创四方向24姿态图集，脚步按实际位移驱动，带接地阴影、呼吸与查看/弯腰动作。多边形地面限制水岸、花坛、崖壁；NPC和婴儿车有实体占位。首四场景及部分后续场景有独立前景，其余前景待补。点出口文字会沿路走到出口，不能隔障碍切房。实际图像提示词保存在assets目录，未使用参考游戏的商业资产。

圆池塘的小船与折纸鸟现在为同一对象：观察前显示小船，观察后以原版段落揭示折纸鸟；位置与ID保持不变，不显示两份物品。对象认知随2D存档保存，不修改原剧情flag。

进场/环顾不重复点名已经画出的已审查物件；主动查看、对话、声音、剧情变化和不可读铭文保留。删除范围按来源和可见状态逐条标记，见[探索文案审查](VISUAL_TEXT_AUDIT.md)，不改原版章节文本。

2D入口独立导入共用GameEngine、Parser、章节和物品，不加载语义模型。T19在授权范围修正共用序章时间，不改GameEngine。2D进度和设置分别保存，与文字版存档隔离。恢复不重放进入事件，死亡不覆盖活档，坏导入保留已有进度。

目标选择、素材命中与自动走近的根因及后续规范见[交互专项审查](INTERACTION_AUDIT.md)。`tools/browser-interactions.mjs`用真实F/鼠标/触摸验证目标选择、改向取消、小物件与树伞/纸船操作。

普通推车演出使用同画风的固定握柄人物与两朝向车体，按道路寻路和实际路程控制脚步/车轮，结束、跳过及读档使用同一落点。`tools/browser-pram.mjs`以真实F和正常帧率检查推入因弗内斯台，另验后续推车、暂停/地图、保存与跳过；四段轮/脚接地由`checks/pram-motion.test.mjs`覆盖。原风驱失控保持独立处理。

原版纸鸟的“四点钟”不是排他准入时刻：撞车抵湖后手表固定3:59:45，导弹/白门事件继续推进，下水也不必先等门。原版核实、旧档估算及本批验收范围见[时间机制记录](../PROLOGUE_TIME_AUDIT.md)。时间、危险阶段由规则层统一保存，M/Esc/文字阅读和动画时长不推动它们。

验证方式：

```sh
npm run verify
npm test
node --test prototype/2d-demo/checks/*.test.mjs
node prototype/2d-demo/tools/audit-scenes.mjs
node prototype/2d-demo/tools/review-navigation.mjs
```
