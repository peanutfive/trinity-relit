# T46–T47 河岸候船与岸上交互

2026-11-24，原版 Release 12（860926），二维参照基线 `0693f9b`。此处的河岸指异境的 The River，玩家仍站在沙岸上。

## 岸上可以发现什么

| 玩家所在状态 | 原版实测 | 本批二维验收目标 |
| --- | --- | --- |
| 船已在视野内，观察船身 | 能辨认出船体很大、形制古老。观察只消耗一次普通动作，玩家留在原岸。 | 在船身使用 F 或点按，可先观察。 |
| 船夫还在艇上，玩家空手观察 | 可看见兜帽遮住面容与身形，年迈的船夫操船沉稳。初见时主动观察过他，随后船靠近，旁白会省去首次辨认船夫的那句。 | 船夫有独立的指向位置。空手观察他，继续留在岸上。 |
| 在岸上向船夫递银币 | 已在船边也无法付款。银币若在口袋，会先移到手中，仍归玩家。之后船班继续运行。 | 手中选银币点船夫，应得到岸上递币的反馈，银币、付款状态和当前位置均可核对。 |
| 船已消失 | 猜看船身或船夫会得到不可见反馈，回合数保持原值。正常等待可迎来下一班。 | 本批暂沿用既有日晷与渡船表现。重复船班留给后续制作。 |

原版陆上观察不会触发登船。进行岸上观察时不加分；等待期间，乘客交的是乘客自己的船资。现有二维继续保留 α 开放后登岛的入口，验收时分别操作船身和船夫，确认仍可接着原路线抵达小岛。

## 首班与再靠岸

从首次见船的正常存档恢复，计数器显示 105 moves。其后每次主动查看携带的银币恰过一回合，可以把船班逐回合复现。

| 原版 moves | 岸上的可见变化 |
| --- | --- |
| 105 | 初次从雾里看到船影。 |
| 106 | 船靠近，通常能辨出船尾的船夫。 |
| 107 | 船停稳，沙岸聚起披衣的身影。穿裹尸布的玩家此时已经可以登船。 |
| 108 | 乘客登船、交银币、落座。 |
| 109 | 最后一名乘客坐下，船仍能登。 |
| 110–111 | 船先离岸，然后消失在雾中。 |
| 112–116 | 逐回合观察随身物品，岸上无新船影。 |
| 117–119 | 船再次现身、靠近、停稳。第二次出现用复见反馈。 |

原版连续输入八次 `wait` 也可从 105 到 117。最后两次分别从 111 到 115、从 115 到 117。在这一状态下两次现身相隔 12 个游戏回合。驶出视野后一直猜看船只不会推进时间。离岸去邻近的楼梯脚再折返，船班也照常推进，房间重入不会重置初见。

**怎样确定首班的第一回合。** 把首次进入河岸后用 `score` 读到的回合数记作 A。走进河岸的这一步已计入 A，当场就见到船影。第一个登艇窗口是 A+2 至 A+4，A+5 离岸，A+6 至 A+11 看不见船，A+12 再现。举例说，从总回合 104 的楼梯脚立刻入岸，A 是 105；先在楼梯脚查看银币四次再入岸，A 是 109，下一次见船在 121。独立将入岸延迟 0、1、4、11、12、13 回合，六种情况下都在 A 首见并在 A+12 再见。

## 本机复现与英文依据

T47–T48 已把上述时刻接入二维版。船在沙洲东侧卸客，随后空船离开。T49 从同一份正常付款的 `paid.qzl` 独立复核了两岸。留在沙洲尝试观察毒菌、观察门、入门，三次均得到不可见反馈。向南才抵达小岛。在这份存档中，影尖正对开门，入门后的原版地点标题是 **Shack**（沙漠金属棚屋）。当影尖只落在毒菌附近，同一扇门仍关着。更换符号、放下拉杆并不能单独证明影尖已经对准门。

T50 从同一份已对准的 `stairs.qzl` 独立分支试玩。每条分支最后都乘船付款、上岛并检查门与影尖。

## T50 影尖与小岛白门

2026-11-25 从同一份 `stairs.qzl` 复测。逐个将影尖锁准在七个符号上，各自穿布付费渡河到岛：第一至第六均门闭且看不到影尖，第七才门开。铜环显示第七时还需观察影尖；恰好停在符号上时门开，已经越过少许时门闭，手推也推不开。

- **船前修正。** 在影尖原本对准第七时，抬杆再压杆就会锁在第七稍后。保持杆压下，将环转到第六再转回第七，影尖重新对中。两条路线都实际付费渡河，再从沙洲南行至门外核对。
- **运动时机。** 抬杆，实际转至第六再转回第七，立即压杆会对中。中间插入一次查看手表再压杆，会锁在第七稍后。影尖持续运动时，在小岛观察白门可见它连续开两回合后关上；在上述错位已锁的对照档中，连续 170 次查看门都闭着。影尖移近和远离时在岛上可见，其他符号或两符号之间的远影在岛上无法辨认。
- **重新选择符号。** 以转回第七后的单回合动作计，延迟 8 回合再锁，铜环显示第一，影尖在第一之前，重新选第一会使它对中。延迟 12 回合时已经对中，延迟 20 回合时影尖已在第一和第二之间，这两种情况下再次选第一都不会转动。是否实际转环不能仅从上一次手选的编号推断。

## T52 初次登台与指针

原版正常新开局的第 5、6 条输入记录了在序章拧松和拾取指针，第 46 条首次登上异境顶台，第 47 条将随玩家过章的同一枚指针装入盘心。本机可从标题重放至第 46 条，分别进行下列检查。

本机 `artifacts/agent-team/evidence/t52-vertex-reference/` 提供三个独立可载入的复现起点：`preinstall.qzl` 是携针初登，`installed.qzl` 是首次安装后，`on-dial.qzl` 是拧下后指针仍在盘面。同目录 `source.json` 记录创建输入与文件哈希。

| 原版可观察的条件 | 实测结果 |
| --- | --- |
| 盘心空着 | 孔内可见螺纹，盘沿仍有七个符号和罗盘。观察影子会看到地面上巨大的投影。铜环可以徒手转动，但还没有用来指认某一档的标记，指定转至第七会被拒绝。此时找不到拉杆。 |
| 针与孔的手性 | 从序章携针直奔顶台，针底螺栓左旋，盘孔右旋，安装失败。携针穿过一次凉亭，两者均左旋，安装成功。将指针留在地上，空手穿过一次再取回，盘孔左旋而针为右旋，仍会失败。先携针过一次，再放下它空手穿第二次，盘孔和螺栓均右旋，也能安装。 |
| 手中有序章指针 | `put gnomon in hole` 首次安装加 5 分，指针离开手中，环上显出箭头，拉杆从地板升起，此时处于抬起状态。单纯放在表面不会安装；已经丢在地上的指针需要先拾取。 |
| 欲收回已安装的指针 | 直接拿只会晃动。用 `unscrew gnomon` 后指针落在盘面，环上箭头消失，拉杆缩回。再用 `take gnomon` 才真正拿到手中，能再次装入，不重复计分。 |
| 已经锁准后拆下 | 第六符号锁准时，从顶台下楼向东到荒野可见白门开启。拆针后走相同路线，先前那扇门已经消失，影尖继续移动。第七符号锁准后拆针，渡河仍能完成，到岛时门闭。两处门分别核验；其他地点尚未逐门测试。 |

**二维旧档兼容边界。** 早期二维版把顶台指针画成固定道具，同时另存序章携带物。旧档里仅有符号编号、影尖计数或序章的拧松记录，均不能证明玩家已在顶台执行过安装。迁移验收应覆盖三种情况：尚未登台且持有指针、已走过旧顶台并开放后续路线、按新规则拆下后将指针留在盘面。分别核对原有进度、物品唯一位置、影尖与得分，尤其要防止重载后又给出第二枚指针或再次奖励 5 分。此段为二维迁移目标，原版试玩依据见上表。

二维正式入口已用同一枚针复走。空手可察看盘孔，手持指针时可查看螺栓并尝试配合。拧下后能在盘心旁看见松针，拾取和重新安装分作两次动作。沿用既有二维操作的地方有两处：F 逐档转环；其余区域沿用已发布的符号与章节对应关系。原版此处额外核对的是拆针后荒野门的消失。
