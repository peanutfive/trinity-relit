# T46–T47 河岸候船与岸上交互

2026-11-24，原版 Release 12（860926），二维参照基线 `0693f9b`。此处的河岸指异境的 The River，玩家仍站在沙岸上。

## 岸上可以发现什么

| 玩家所在状态 | 原版实测 | 本批二维验收目标 |
| --- | --- | --- |
| 船已在视野内，观察船身 | 能辨认出船体很大、形制古老。观察只消耗一次普通动作，玩家留在原岸。 | 在船身使用 F 或点按，可先观察。 |
| 船夫还在艇上，玩家空手观察 | 可看见兜帽遮住面容与身形，年迈的船夫操船沉稳。初见时主动观察过他，随后船靠近，旁白会省去首次辨认船夫的那句。 | 船夫有独立的指向位置。空手观察他，继续留在岸上。 |
| 在岸上向船夫递银币 | 已在船边也无法付款。银币若在口袋，会先移到手中，仍归玩家。之后船班继续运行。 | 手中选银币点船夫，应得到岸上递币的反馈，银币、付款状态和当前位置均可核对。 |
| 船已消失 | 猜看船身或船夫会得到不可见反馈，回合数保持原值。正常等待可迎来下一班。 | 本批暂沿用既有日晷与渡船表现。重复船班留给后续制作。 |

原版陆上观察不会触发登船。进行岸上观察时不加分；等待期间，乘客交的是乘客自己的船资。现有二维继续保留 α 开放后登岛的入口，验收时分别操作船身和船夫，确认仍可接着原路线抵达小岛。

## 首班与再靠岸

从首次见船的正常存档恢复，计数器显示 105 moves。其后每次主动查看携带的银币恰过一回合，可以把船班逐回合复现。

| 原版 moves | 岸上的可见变化 |
| --- | --- |
| 105 | 初次从雾里看到船影。 |
| 106 | 船靠近，通常能辨出船尾的船夫。 |
| 107 | 船停稳，沙岸聚起披衣的身影。穿裹尸布的玩家此时已经可以登船。 |
| 108 | 乘客登船、交银币、落座。 |
| 109 | 最后一名乘客坐下，船仍能登。 |
| 110–111 | 船先离岸，然后消失在雾中。 |
| 112–116 | 逐回合观察随身物品，岸上无新船影。 |
| 117–119 | 船再次现身、靠近、停稳。第二次出现用复见反馈。 |

原版连续输入八次 `wait` 也可从 105 到 117。最后两次分别从 111 到 115、从 115 到 117。在这一状态下两次现身相隔 12 个游戏回合。驶出视野后一直猜看船只不会推进时间。离岸去邻近的楼梯脚再折返，船班也照常推进，房间重入不会重置初见。

**怎样确定首班的第一回合。** 把首次进入河岸后用 `score` 读到的回合数记作 A。走进河岸的这一步已计入 A，当场就见到船影。第一个登艇窗口是 A+2 至 A+4，A+5 离岸，A+6 至 A+11 看不见船，A+12 再现。举例说，从总回合 104 的楼梯脚立刻入岸，A 是 105；先在楼梯脚查看银币四次再入岸，A 是 109，下一次见船在 121。独立将入岸延迟 0、1、4、11、12、13 回合，六种情况下都在 A 首见并在 A+12 再见。

## 日晷与跨章边界

七个符号都允许原版渡船载客。另从尚未转过第七符号的墓地存档直接去河岸，保持先前的第六符号，也会首次见船并靠岸。表中序号来自原版铜环的观察结果；二维版使用自己的符号编号。

二维 α 入口、登岸地点和既有返程属于当前改编。T46 的发布验收只覆盖岸上观察、递币拒收以及原有路线可继续通行。若后续制作原版船班，可沿用上表核对状态，另验穿着、船上付款与沙洲登岸。

## 本机复现与英文依据

T47–T48 已把上述时刻接入二维版。船在沙洲东侧卸客，随后空船离开。T49 从同一份正常付款的 `paid.qzl` 独立复核了两岸。留在沙洲尝试观察毒菌、观察门、入门，三次均得到不可见反馈。向南才抵达小岛。在这份存档中，影尖正对开门，入门后的原版地点标题是 **Shack**（沙漠金属棚屋）。当影尖只落在毒菌附近，同一扇门仍关着。更换符号、放下拉杆并不能单独证明影尖已经对准门。

T50 从同一份已对准的 `stairs.qzl` 独立分支试玩。每条分支最后都乘船付款、上岛并检查门与影尖。

| 顶台上的操作 | 上岛观察 |
| --- | --- |
| 直接去河岸，或上顶台只看铜环再下楼 | 影尖对准开门，可走进金属棚屋。 |
| 抬杆，未转环便压下；或再指定当前的第七符号才压杆 | 影尖只落在毒菌旁，门关闭。 |
| 抬杆，转到第六，再转回第七，随即压杆 | 影尖对准门，门打开。转到第一再转回第七也可复现。 |

在上述关门分支中，杆保持压下，依次转到第六、第七便能修正。两个分支的铜环都指着第七符号。在顶台检查影尖才看得出它恰好停在符号上，还是已经略微越过。小岛菌门的二维接入须保留这个可观察的区别。

另一次对照只改变了压杆的时刻。抬杆、转六、转七后立即压杆，影尖停在第七；先看一次手表再压杆，影尖略过第七；先看十二次再压杆，影尖已到第一。以上调整都在出航前完成。
